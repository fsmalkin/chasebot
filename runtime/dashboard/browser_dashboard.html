    Current Capability Boundary

    What the system has now

    These are the current capabilities the operator can trust and rehearse.

    • Perception from the current target pipeline
    • Goal creation and motion execution through the frozen control path
    • Track, abort, and safe_stop through the fixed intent boundary

    What the future LLM would sit on top of

    This is the real substrate an LLM layer would be allowed to use.

    • The frozen intent boundary
    • Current perception and state signals
    • Returned feedback and outcome signals

    What is not here yet

    The dashboard should stay honest about the current limits.

    • Freeform language understanding
    • Open-ended planning or task decomposition
    • Unbounded action selection outside the frozen set
    How To Use This

    For the full walkthrough, use docs/DASHBOARD_OPERATOR_GUIDE.md. This drawer keeps the common operator path on the page.

    1. Open Docker Desktop, click play on the Chasecar app, then open http://127.0.0.1:8860.
    2. Use the Next Step card to start the environment and wait for the world and topdown views to update.
    3. Run m3_single_target first, then m3_center, m3_left, m3_right, and finally multi_target_rehearsal.
    4. Use the What To Watch panel to judge whether the run looks healthy before opening Advanced Controls.
    5. Use Reset Sim if you want a fresh session id and Stop Environment when you are done.
    6. Open Advanced Controls only when you want the workbench lanes, the frozen-intent console, or deeper control-plane detail.
