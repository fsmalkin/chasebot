    How To Use This

    For the full walkthrough, use docs/DASHBOARD_OPERATOR_GUIDE.md. This drawer keeps the common operator path on the page.

    1. Open Docker Desktop, click play on the Chasecar app, then open http://127.0.0.1:8860.
    2. Start the environment and wait for the world and YOLO debug views to go live.
    3. Run LLM Turn + Go first. The robot should turn until it sees the ball, then move toward it.
    4. Use the run log to confirm the same high-level LLM and robot steps you see in the visuals.
    5. Use Reset Sim if you want a fresh session id and Stop Environment when you are done.
    6. Open Advanced Controls only when you want raw camera, topdown telemetry, workbench detail, or manual tools.
